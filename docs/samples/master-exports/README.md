# Master software export samples

Owner Crystal Reports exports (`.xls` / `.pdf`). Generic **Import** on each list accepts templates; when you upload from the products or retailers import screen with these filenames, column headers map automatically:

- `ProductList*` → products import
- `SalesRegister*` → retailers import (codes/names; not full invoices)

Stock register PDFs are **not** imported here — use **Stock → Compare with export** (CSV/XLSX). See DECISIONS #106.
